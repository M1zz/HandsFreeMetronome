낫마템포

손 없이 쓰는 메트로놈 · 튜너 — 도움말
App Store에서 받기
메트로놈의 모든 기능과 손 없이 쓰는 음성 조작은 무료입니다. Not My Tempo Pro에는 연습 모드, 악센트 에디터·프리셋, 크로매틱 튜너가 들어 있고, 무료 체험이 있는 연간 구독이나 한 번 결제로 평생 쓸 수 있습니다.
음성 조작과 접근성 기능은 앞으로도 누구에게나 무료입니다. Pro가 생기기 전에 앱을 구매하셨다면 Pro 기능을 이미 모두 쓰실 수 있습니다.

어떤 앱인가요

낫마템포는 연주하는 동안 목소리만으로 조작하는 메트로놈입니다. 화면을 누를 필요도 없고, iOS의 음성 제어나 손쉬운 사용 설정을 따로 켤 필요도 없습니다. 크로매틱 튜너도 함께 들어 있습니다.

시작하기

1. 앱을 열면 바로 듣기가 시작됩니다.
2. 처음 한 번 마이크와 음성 인식 권한을 허용해 주세요.
3. 명령을 말하거나 화면의 버튼을 누르면 됩니다.

팁: 이어폰을 쓰면 클릭 소리가 마이크로 새어 들어가지 않아 음성 인식과 튜너가 더 정확해집니다.

음성 명령

"start" / "stop"재생 / 멈춤
"faster" / "slower"5 BPM씩 올리기 / 내리기
"up" / "down"1 BPM씩 올리기 / 내리기
"tempo 120"원하는 템포로 바로 맞추기
"double" / "half"두 배 / 절반
"three beats"박자 바꾸기
"quarter / eighth / triplet / sixteenth"4분 · 8분 · 셋잇단 · 16분 분할
"louder" / "quieter" / "mute"클릭 소리 크게 / 작게 / 음소거
"volume 60"음량을 퍼센트로 맞추기
"bounce" / "orbit"박 표시 방식 바꾸기
"practice"연습하는 동안 템포를 자동으로 올리기 (Pro)
"tune"튜너 열기 (Pro)
"help"명령 목록 보기
"close" / "done"열린 화면 닫기

음성 인식은 영어(미국)로 동작하므로 명령은 위처럼 영어로 말해 주세요. 모든 명령은 화면의 버튼으로도 할 수 있습니다.

튜너

tune이라고 말하거나 템포 카드의 파형 버튼을 누르세요. 음을 하나 연주해서 표시가 초록색 구간 안에 들어오면 음이 맞은 것입니다. 나갈 때는 close라고 말하면 됩니다.

배터리

배터리를 아끼기 위해 몇 분 동안 명령이 없으면 듣기가 자동으로 꺼집니다. 다시 켜려면 Listen을 누르세요.

문제 해결

제 말을 못 알아들어요. 마이크 상태가 "Listening"으로 표시되는지 확인해 주세요. 꺼져 있다면 Listen을 누르면 됩니다. 시끄러운 곳이나 스피커로 소리를 크게 틀 때는 이어폰을 쓰세요.

템포가 절반이나 두 배로 잡혀요. "double"이나 "half"라고 말해서 바로잡을 수 있습니다.
