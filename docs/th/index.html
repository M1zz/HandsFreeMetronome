ดาวน์โหลดบน App Store
เมโทรนอมเต็มรูปแบบและการควบคุมด้วยเสียงแบบไม่ใช้มือใช้ฟรี Not My Tempo Pro เพิ่มโหมดฝึกซ้อม ตัวแก้ไขเสียงเน้นพร้อมค่าที่ตั้งไว้ และเครื่องตั้งสายโครมาติก ผ่านการสมัครรายปีพร้อมทดลองใช้ฟรี หรือซื้อแบบตลอดชีพครั้งเดียว
การควบคุมด้วยเสียงและฟีเจอร์การช่วยการเข้าถึงใช้ฟรีสำหรับทุกคนตลอดไป ซื้อแอปก่อนมี Pro ใช่ไหม ฟีเจอร์ Pro ทั้งหมดเป็นของคุณแล้ว

แอปนี้คืออะไร

Not My Tempo คือเมโทรนอมที่คุณควบคุมด้วยเสียงทั้งหมดขณะเล่นดนตรี ไม่ต้องแตะหน้าจอ และไม่ต้องเปิดการควบคุมด้วยเสียงของ iOS หรือ การตั้งค่าการช่วยการเข้าถึงใด ๆ ในแอปยังมีเครื่องตั้งสายโครมาติกให้ด้วย

เริ่มต้นใช้งาน

1. เปิดแอป แอปจะเริ่มฟังทันที
2. อนุญาตการเข้าถึงไมโครโฟนและการรู้จำเสียงพูดในครั้งแรก
3. พูดคำสั่ง หรือแตะปุ่มควบคุม

เคล็ดลับ: ใช้หูฟังเพื่อไม่ให้เสียงคลิกเข้าไมค์ จะช่วยให้การรู้จำเสียงพูดและเครื่องตั้งสายแม่นยำ

คำสั่งเสียง

"start" / "stop"เล่น / หยุดชั่วคราว
"faster" / "slower"±5 BPM
"up" / "down"±1 BPM
"tempo 120"ตั้งค่าที่ต้องการ
"double" / "half"×2 / ÷2
"three beats"ตั้งอัตราจังหวะ
"quarter / eighth / triplet / sixteenth"การแบ่งจังหวะย่อย
"louder" / "quieter" / "mute"ระดับเสียงคลิก
"volume 60"ตั้งระดับเสียงเป็นเปอร์เซ็นต์
"bounce" / "orbit"สลับมุมมองจังหวะ
"practice"เพิ่มความเร็วอัตโนมัติขณะฝึกซ้อม (Pro)
"tune"เปิดเครื่องตั้งสาย (Pro)
"help"แสดงรายการคำสั่ง
"close" / "done"ปิดแผง

คำสั่งใช้คำภาษาอังกฤษ (การรู้จำใช้ภาษาอังกฤษแบบอเมริกัน) และสั่งงานได้ด้วยการแตะปุ่มควบคุมบนหน้าจอเช่นกัน

เครื่องตั้งสาย

พูดว่า tune (หรือแตะปุ่มรูปคลื่นบนการ์ดความเร็ว) แล้วเล่นโน้ตหนึ่งตัว เมื่อเข็มเข้าโซนสีเขียว แสดงว่าเสียงตรงแล้ว พูดว่า close เพื่อออก

แบตเตอรี่

เพื่อประหยัดแบตเตอรี่ การฟังจะปิดเองหากไม่มีคำสั่งเป็นเวลาไม่กี่นาที แตะฟังเพื่อเปิดใหม่

การแก้ปัญหา

แอปไม่ได้ยินเสียงฉัน ตรวจสอบว่าสถานะไมค์เป็น “กำลังฟัง” หากปิดอยู่ ให้แตะ “ฟัง” ในห้องที่มีเสียงดังหรือเมื่อเล่นผ่านลำโพง ให้ใช้หูฟัง

ความเร็วที่ตรวจพบเป็นครึ่งหนึ่งหรือสองเท่า พูดว่า “double” หรือ “half” เพื่อแก้ไข
