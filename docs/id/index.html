Not My Tempo

Metronom dan tuner bebas tangan — Dukungan
Unduh di App Store
Metronom lengkap dan kontrol suara bebas tangan sepenuhnya gratis. Not My Tempo Pro menambahkan mode latihan, editor aksen dengan preset, dan tuner kromatik — sebagai langganan tahunan dengan uji coba gratis, atau pembelian seumur hidup sekali bayar.
Kontrol suara dan fitur aksesibilitas tetap gratis untuk semua orang, selamanya. Membeli aplikasi sebelum ada Pro? Semua fitur Pro sudah menjadi milikmu.

Apa itu

Not My Tempo adalah metronom yang sepenuhnya kamu kendalikan dengan suara saat bermain — tanpa mengetuk layar, dan tanpa perlu menyalakan Kontrol Suara iOS atau pengaturan aksesibilitas lainnya. Aplikasi ini juga memiliki tuner kromatik bawaan.

Mulai menggunakan

1. Buka aplikasi — langsung mulai mendengarkan.
2. Izinkan akses Mikrofon dan Pengenalan Ucapan saat pertama kali.
3. Ucapkan perintah, atau ketuk kontrolnya.

Tips: pakai earphone agar suara klik tidak masuk ke mikrofon — ini menjaga pengenalan ucapan dan tuner tetap akurat.

Perintah suara

"start" / "stop"putar / jeda
"faster" / "slower"±5 BPM
"up" / "down"±1 BPM
"tempo 120"atur nilai tertentu
"double" / "half"×2 / ÷2
"three beats"atur birama
"quarter / eighth / triplet / sixteenth"subdivisi
"louder" / "quieter" / "mute"volume klik
"volume 60"atur volume dalam persen
"bounce" / "orbit"ganti tampilan ketukan
"practice"tempo naik otomatis saat berlatih (Pro)
"tune"buka tuner (Pro)
"help"tampilkan daftar perintah
"close" / "done"tutup panel

Perintah diucapkan dalam bahasa Inggris (pengenalan memakai bahasa Inggris Amerika). Setiap perintah juga bisa diberikan dengan mengetuk kontrol di layar.

Tuner

Ucapkan tune (atau ketuk tombol gelombang di kartu tempo). Mainkan sebuah not: saat penunjuk masuk ke zona hijau, nadamu sudah pas. Ucapkan close untuk keluar.

Baterai

Untuk menghemat baterai, fitur mendengarkan mati sendiri jika tidak ada perintah selama beberapa menit. Ketuk Dengarkan untuk menyalakannya lagi.

Pemecahan masalah

Tidak mendengar saya. Pastikan status mikrofon “Mendengarkan”. Jika mati, ketuk “Dengarkan”. Di ruangan bising atau saat bermain lewat speaker, gunakan earphone.

Tempo yang terdeteksi setengah atau dua kali lipat. Ucapkan “double” atau “half” untuk memperbaikinya.
