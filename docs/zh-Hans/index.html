这是什么

Not My Tempo 是一款边演奏边完全用语音操控的节拍器， 无需点屏幕，也无需开启 iOS 系统的语音控制或任何辅助功能设置。 它还内置一个半音阶调音器。

快速上手

1. 打开 App，它会自动开始聆听。
2. 首次使用时允许访问麦克风和语音识别。
3. 直接说出指令，或轻点屏幕上的控件。

提示：建议戴上耳机，避免节拍声被麦克风收进去， 这样语音识别和调音器都会更准确。

语音指令

"start" / "stop"播放 / 暂停
"faster" / "slower"±5 BPM
"up" / "down"±1 BPM
"tempo 120"设定精确数值
"double" / "half"×2 / ÷2
"three beats"设定拍号
"quarter / eighth / triplet / sixteenth"细分
"louder" / "quieter" / "mute"节拍音量
"volume 60"设定音量百分比
"bounce" / "orbit"切换节拍视图
"practice"练习时自动逐步提速（Pro）
"tune"打开调音器（Pro）
"help"显示指令列表
"close" / "done"关闭面板

语音指令需用英文说出（识别语言为美式英语）。每条指令也都可以通过 轻点屏幕上的控件完成。

调音器

说 tune（或轻点速度卡片上的波形按钮）。弹奏一个音， 指示针落入绿色区域就表示音准了。说 close 退出。

电池

为了省电，如果几分钟内没有收到指令，聆听会自动关闭。 轻点聆听即可重新开启。

故障排除

它听不到我说话。请确认麦克风状态显示为“正在聆听”。 如果已关闭，请轻点“聆听”。在嘈杂的房间或使用扬声器外放时，请戴上耳机。

识别出的速度刚好是一半或两倍。说“double”或“half”即可纠正。
