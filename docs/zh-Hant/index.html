這是什麼

Not My Tempo 是一款演奏時完全用語音操控的節拍器， 不必點螢幕，也不必開啟 iOS 系統的語音控制或任何輔助使用設定。 它還內建一個半音階調音器。

快速上手

1. 開啟 App，它會自動開始聆聽。
2. 第一次使用時，請允許存取麥克風與語音辨識。
3. 直接說出指令，或點選畫面上的控制項。

提示：建議戴上耳機，避免點擊聲被麥克風收進去， 這樣語音辨識與調音器都會更準確。

語音指令

"start" / "stop"播放／暫停
"faster" / "slower"±5 BPM
"up" / "down"±1 BPM
"tempo 120"設定確切數值
"double" / "half"×2 / ÷2
"three beats"設定拍號
"quarter / eighth / triplet / sixteenth"細分
"louder" / "quieter" / "mute"點擊音量
"volume 60"設定音量百分比
"bounce" / "orbit"切換拍子檢視
"practice"練習時自動逐步加快（Pro）
"tune"開啟調音器（Pro）
"help"顯示指令列表
"close" / "done"關閉面板

語音指令需用英文說出（辨識語言為美式英文）。每個指令也都可以 改用點選畫面上的控制項來完成。

調音器

說 tune（或點選速度卡片上的波形按鈕）。彈奏一個音， 指針落在綠色區域就表示音準正確。說 close 即可離開。

電池

為了省電，如果幾分鐘內沒有收到指令，聆聽會自動關閉。 點選聆聽即可重新開啟。

疑難排解

它聽不到我說話。請確認麥克風狀態顯示為「聆聽中」。 若已關閉，請點選「聆聽」。在吵雜的空間或使用喇叭外放時，請戴上耳機。

辨識出的速度剛好是一半或兩倍。說「double」或「half」即可修正。
