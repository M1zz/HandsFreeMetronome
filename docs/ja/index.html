Not My Tempoとは

Not My Tempoは、演奏しながら声だけで操作できるメトロノームです。 画面をタップする必要はなく、iOSの音声コントロールやアクセシビリティの設定をオンにする必要もありません。 クロマチックチューナーも内蔵しています。

はじめかた

1. アプリを開くと、自動で聞き取りが始まります。
2. 初回はマイクと音声認識へのアクセスを許可してください。
3. あとはコマンドを話すか、画面のボタンをタップするだけです。

ヒント：クリック音がマイクに入らないようイヤホンを使うと、音声認識とチューナーがより正確になります。

音声コマンド

"start" / "stop"再生 / 停止
"faster" / "slower"±5 BPM
"up" / "down"±1 BPM
"tempo 120"数値でテンポを指定
"double" / "half"×2 / ÷2
"three beats"拍子を設定
"quarter / eighth / triplet / sixteenth"細分（4分 / 8分 / 3連符 / 16分）
"louder" / "quieter" / "mute"クリックの音量
"volume 60"音量をパーセントで指定
"bounce" / "orbit"ビート表示を切り替え
"practice"練習しながらテンポを自動で上げる（Pro）
"tune"チューナーを開く（Pro）
"help"コマンド一覧を表示
"close" / "done"パネルを閉じる

音声コマンドは英語（米国）で話します。日本語のコマンドには対応していません。 どのコマンドも、画面のボタンをタップして同じ操作ができます。

チューナー

tuneと話すか、テンポカードの波形ボタンをタップします。音を鳴らして、 インジケーターが緑の範囲に入れば音が合っています。closeと話すと閉じます。

バッテリー

電池を節約するため、コマンドがないまま数分たつと聞き取りは自動でオフになります。 聞き取りをタップすると再びオンになります。

困ったときは

声を聞き取ってくれない。マイクの状態が「聞き取り中」になっているか確認してください。 オフになっていたら「聞き取り」をタップします。騒がしい場所やスピーカーで鳴らしているときは、イヤホンを使ってください。

検出したテンポが半分や倍になる。「double」または「half」と話して直してください。
